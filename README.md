# Nikhil's Portfolio 🚀

A modern, responsive portfolio website built with cutting-edge web technologies and best practices.

## ✨ Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Mobile-first approach with perfect display on all devices
- **Dark/Light Mode**: Automatic theme switching with system preference detection
- **Performance Optimized**: Lazy loading, optimized images, and efficient code
- **Accessibility**: WCAG 2.1 compliant with proper ARIA labels
- **SEO Ready**: Meta tags, structured data, and semantic HTML
- **Modern JavaScript**: ES6+ modules with clean architecture
- **CSS Grid & Flexbox**: Modern layout techniques
- **Smooth Animations**: Intersection Observer API for scroll animations
- **Contact Form**: Modern form with validation and feedback

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Custom properties, Grid, Flexbox, animations
- **JavaScript ES6+**: Modules, async/await, modern APIs
- **Font Awesome**: Icons and social media links
- **Google Fonts**: Inter font family

### Development Tools
- **Live Server**: Development server
- **Clean CSS**: CSS minification
- **Terser**: JavaScript minification
- **Lighthouse**: Performance auditing

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nikhil-dex/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

This will:
- Minify CSS files
- Minify JavaScript files
- Optimize for production

## 🎨 Customization

### Colors
Update CSS custom properties in `styles/main.css`:

```css
:root {
  --primary-color: #6366f1;
  --secondary-color: #f59e0b;
  --accent-color: #ec4899;
  /* ... more variables */
}
```

### Content
- **Personal Information**: Update `index.html` with your details
- **Projects**: Modify the projects section with your work
- **Social Links**: Update social media links in the footer
- **Contact Information**: Update contact details

### Styling
- **Typography**: Change font family in CSS variables
- **Layout**: Modify grid and flexbox properties
- **Animations**: Adjust animation durations and effects
